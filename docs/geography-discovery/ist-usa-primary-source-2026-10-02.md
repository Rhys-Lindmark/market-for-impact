# IST primary regulatory forecast challenge

Root independently opened the [2023 NHTSA/FMCSA heavy-vehicle AEB proposed rule](https://www.nhtsa.gov/sites/nhtsa.gov/files/2023-06/NPRM_HV-AEB-for-web.pdf), tables5 and19 and associated text, on October2. Ten-second clock-resolution source interval is closed separately; subsequent drafting/discussion is not research time.

- AEB-only forecast:106 fatalities and8,058 nonfatal injuries annually across the modeled classes. Class7–8 row40 fatalities/2,822 injuries combines AEB and ESC; it is not AEB-only class evidence.
- Table19 text describes benefits for the fleet not already voluntarily equipped before the proposal and includes reduced dark/weather performance. Only subsequent adoption erosion belongs in an additional haircut.
- Benefits build through fleet replacement, not immediate whole-fleet installation. Other-road-user injury/death projections are not an IST-attributed observed cohort.
- False activations and sensor degradation are unquantified possible harms. A harm test must not disappear merely because gross utility is set to zero.
- The$353M annual cost combines technologies. Regulatory monetized safety benefits and fatal-equivalent values are not net household cash or income. Producer costs, insurance and actual household incidence require distinct treatment.

These constraints were sent to the implementer. No current model price, publication count or source date was changed by this audit.
